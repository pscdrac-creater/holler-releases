# Holler

Installers for Holler, the office walkie-talkie that works over Tailscale.

**Download:** open [the latest release](https://github.com/pscdrac-creater/holler-releases/releases/latest) and pick

- Mac (Apple silicon or Intel, macOS 14.2 or later): `Holler_<version>_universal.dmg`
- Ubuntu or Debian: `Holler_<version>_amd64.deb`
- Windows: `Holler_<version>_x64-setup.exe`

Installed copies update themselves from this page. Holler's source code is not public; this repository only holds the installers.
